Download a backup

A zip with a current copy of the database: your whole attack-surface inventory. Your password is asked again.

Restore

Restoring replaces the whole database, so it is done on the server with LazyEASM stopped. The database it replaces is kept as a pre-restore backup.

python -m utils.backup list
python -m utils.backup restore db/backups/<file>.db      # or a downloaded .zip
python -m utils.backup restore backup.zip --with-env       # also restore .env from the zip

Change admin password

Other signed-in sessions are signed out. Lost the password? Add ADMIN_PASS=... to .env and restart LazyEASM.
